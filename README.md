Návrh a implementácia programovacieho prostredia pre jazyk Python

Začínajúci programátori často používajú integrované vývojové prostredia (Integrated Development Environment, IDE), ktorých dizajn a funkcionality sú prispôsobené ich potrebám. Minimalistické programovacie prostredie s kompaktným, jednoduchým používateľským rozhraním, s integrovanou vizualizáciou výpočtu a ďalšími pomocnými modulmi, môže začiatočníka podporiť pri vytváraní správnych predstáv, hlbšom porozumení súvislostí a trénovaní programátorských zručností.

Cieľ práce:
- navrhnúť  zjednodušené IDE pre programovací jazyk Python, ktoré bude vhodné pre začínajúcich programátorov,
- riešenie implementovať ako desktopovú aplikáciu v jazyku Python.

Charakter práce:
vývoj softvéru – analýza riešeného problému, návrh softvéru, implementácia, popis vytvoreného softvéru, testovanie. 

Predmetové prerekvizity:
- Programovanie (1., Bc.),
- Softvérové inžinierstvo (1., Mgr.).

Najdôležitejšie kompetentnosti získané spracovaním témy:
- analýza softvérovej architektúry,
- formulácia požiadaviek na vývoj softvéru, 
- návrh používateľského rozhrania aplikácie,
- implementácia a testovanie vyvíjaného softvéru, 
- kritické myslenie, tvorivosť.
